Glyph Lab · Proof reference → vector capture → on-model variation → new compositions. Click any generated frame to reroll.

1 · Capture

Left: the reference frame. Right: our vector recreation — the reference was auto-traced into polygon templates (color segmentation + contour simplification, ~15–25 points per glyph). This is the fidelity ceiling of the format: the shape language survives vectorization intact.

2 · Vary — same design, new takes

Each frame perturbs only what an animator varies between drawings: spike lengths, slight rotation and scale per glyph, edge jitter, regenerated dash confetti. The composition, glyph anatomy, and color roles are never randomized — so every take stays on-model. This is what separates a template bank from noise.

3 · Recompose — same glyphs, different hits

The captured glyphs rearranged into new impact layouts (rotated, mirrored, rescaled per slot). One traced frame yields a whole family of shots — this is the element-bank workflow every FX studio already trusts, made procedural.
